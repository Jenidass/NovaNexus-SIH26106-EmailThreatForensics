# SentinelTrace — Investigation Results Page

Frontend-only investigation results screen for a fictional cybersecurity product, built with React + TypeScript + Vite + Tailwind CSS + Lucide + Recharts. All data is mock/fictional. No backend, AI, email parsing, or real threat-intel API calls.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
